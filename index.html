2023年8月、高校3年でテクノフィアを立ち上げました。2026年10月には、株式会社Technophere として法人化。ゲーム攻略メディアを軸に、SEOと解析で読者を増やし、いまは自分のアプリやプラグインもつくっています。設計から実装、ストア公開、リリース後の改善まで、すべて自分の手で。AIは開発の中心にありますが、最後にコードを読むのは自分の目です。

つくったもの

ストアで配信しているアプリと、公開しているサービス・プラグインです。

BrawlTech

ブロスタの戦略サポートアプリ

2.0 で全面的に作り直しました。ブロスタ攻略Lab に集まる実際の対戦データから、開催中のマップで勝っているキャラをひと目で表示。マップ別の勝率ランキング、ガチバトルの BAN/PICK 補助、全キャラ図鑑と比較、戦績分析と育成計画まで、ひとつのアプリにまとめています。Flutter で iOS と Android に対応し、データは WordPress の API と Cloud Functions から配信しています。

  • Flutter
  • Riverpod
  • Firebase
  • WordPress REST API

KPass

慶應生の授業と課題をひとつにするアプリ

大学の学習支援システム K-LMS（Canvas）の API から授業・課題・時間割を取り込み、アプリの中で整理して表示します。ログインを数日保持し、課題の締切もひと目で確認できます。SwiftUI と Kotlin Multiplatform で iOS と Android に対応し、2025年12月に公開。App Store の評価は 4.4（173件）です。

  • SwiftUI
  • Kotlin Multiplatform
  • Firebase
  • Canvas API

ZeroShot

縦と横を同時に撮れる、失敗しないカメラ

シャッター1回で、縦と横の構図を同時に保存。前後のフレームからブレや目つぶりの少ない1枚を端末の中で選び、写真ライブラリへ自動で保存します。寄りや別レンズの候補も残るので、撮った後に選び直せます。SwiftUI と AVFoundation で開発し、2026年9月に公開しました。

  • SwiftUI
  • AVFoundation
  • Vision
  • Core Image
