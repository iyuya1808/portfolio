つくったもの

ストアで配信しているアプリです。

BrawlTech

ブロスタの戦略サポートアプリ

ブロスタ攻略Lab に集まる対戦データから、開催中のマップで勝っているキャラをひと目で表示します。マップ別の勝率、BAN/PICK の補助、戦績分析までひとつに。Flutter で iOS と Android に対応しています。

  • Flutter
  • Riverpod
  • Firebase
  • WordPress REST API

KPass

慶應生の授業と課題をひとつにするアプリ

大学の K-LMS から授業・課題・時間割を取り込み、ひとつの画面にまとめます。締切もひと目で確認できます。2025年12月公開。いまは慶應生の15%以上が使っていて、App Store の評価は 4.5 です。

  • SwiftUI
  • Kotlin Multiplatform
  • Firebase
  • Canvas API

ZeroShot

縦と横を同時に撮れる、失敗しないカメラ

シャッター1回で、縦と横の構図を同時に保存。ブレや目つぶりの少ない1枚を、端末の中で選びます。2026年9月公開。

  • SwiftUI
  • AVFoundation
  • Vision
  • Core Image
